# UIコンポーネント

# 画面構成
- 画面は左上・左下・中・右の4ペイン構成とする
  - 左上：枠タイプペイン
     - 「枠タイプ」のリスト
       - 名前・時間長・出演枠属性を表示
     - 枠タイプ作成ボタン
     - ここに並んでいる「枠タイプ」をタイムラインにドラッグすることで実際の「枠」が作成される
     - 縦スクロール可能
     - 空の場合は何も表示しない（作成ボタンだけがある）
  - 左下：演者ペイン
     - 「演者」のリスト
       - 名前・明示されている要求の内容を表示
     - 演者作成ボタン
     - ここに並んでいる「演者」を、タイムラインに配置された「枠」にドラッグすることで、枠に演者が割り当てられる
     - 縦スクロール可能
     - 空の場合は何も表示しない（作成ボタンだけがある）
  - 中：タイムラインペイン
     - 「タイムライン」を配置可能な複数の「レーン」とタイムライン作成ボタン
       - レーンは、左から詰めて横に並べる
       - レーンはドキュメントのタイムラインのリストと対応する
         - タイムラインを削除したらレーンも削除される
       - レーンの幅は固定
     - 縦軸に時間目盛りがある
         - 0時〜30時
         - 24時以降は背景をやや暗い見た目にする
         - 目盛り間隔は絶対でなく、タイムラインオブジェクト・枠オブジェクトの配置によって伸縮する
         - 複数のレーンがある場合、最も高いものに合わせるようにし、レーン間で同じ時刻の縦位置が揃うようにする
     - 縦横スクロール可能
     - 空の場合は何も表示しない（作成ボタンだけがある）
  - 右：プロパティペイン
     - 選択中のオブジェクトのプロパティを表示。プロパティ変更もできる
     - 縦スクロール可能
     - 初期状態はドキュメントのプロパティを表示
- 画面下部に広告領域を設置する
  - 常に一定のピクセル数（高さ）を確保し、そこに広告を表示する
    - 広告のロード有無・成否によってレイアウトが変わらないようにする
    - 具体的な高さは、採用する広告ネットワークの標準バナーサイズに合わせて実装時に決める
  - 4ペインは広告領域を除いた残りの領域に配置する
  - ダイアログ・ボトムシートは広告領域より前面に重なってよい
- 常にアクセス可能なメニューを設置する
  - 以下の機能を提供
    - エクスポート
    - インポート
    - クリア（新規作成）
    - 取り消す（アンドゥ）
    - やり直す（リドゥ）
  - プルダウンとして画面右上に配置
  - アンドゥ・リドゥはショートカットキーも提供
    - 具体的なキーバインドはOSの標準に準じる

# 画面コンポーネント

### タイムテーブル構成コンポーネント

  - タイムラインコンポーネント
    - 表示項目
      - タイムライン名
        - 小さいフォントで表示
      - 内包する枠コンポーネント
        - 内包にあたっては、パディングなしとすることで枠をドラッグ等で移動できない印象とする
        - 隣接する枠コンポーネント間のギャップも不要
    - 幅は固定
    - 高さは内包コンポーネントにより可変
  - 枠コンポーネント
    - 表示項目
      - 枠名
        - 小さいフォントで表示
    - 演者コンポーネント
      - 出演枠属性が付与されている場合のみ
      - １つだけ内包可能
      - 内包にあたっては、若干のパディングをつけ、ドラッグ等で移動できる印象とする
    - 角丸なしとすることで、上記のパディングなしと併せてドラッグ等で移動できない印象とする
    - 幅は親コンポーネントに従う
    - 高さは最低高さがある。演者コンポーネントがある場合、内包できるよう必要に応じて拡張
  - 演者コンポーネント
    - 表示項目
      - 演者名
        - 見やすくはっきりとしたフォントで表示
      - 要求不一致警告
        - 演者の要求と合わない項目がある場合に表示
        - 警告色の小さいフォントで表示
        - 文言は固定（プロパティペインに詳しく表示）
    - 角丸をつけ、上記のパディングと併せてドラッグ等で移動可能な印象とする
    - 幅は親コンポーネントに従う
    - 高さは演者名のテキスト量に従う

### その他コンポーネント

Material Design で用意されているものは新規作成しない。以下はアプリ固有のため作成する。

- 4ペインレイアウト
  - 左上・左下・中・右の配置
  - ペイン幅は固定（境界ドラッグによるリサイズ可能）
- 時間目盛り
  - 0時〜30時。24時以降は背景をやや暗い見た目にする
  - 目盛り間隔はタイムライン・枠の配置によって伸縮する
  - 複数レーンで同じ時刻の縦位置が揃うこと
  - 時刻と縦位置の変換は、目盛り・枠の高さ・挿入バー・ドロップ位置計算で共有する
- レーン
  - タイムラインを1つ載せる領域
  - ドキュメントのタイムラインリストと対応する
  - 空の部分（未作成レーン）へのドロップを受け付ける
- 挿入予定位置バー
  - ドラッグ中のみ表示
  - 枠間スナップ / 開始・終了位置スナップ / 10分解像度、の位置決めに従う
- ドラッグ中ゴースト
  - 枠タイプドラッグ時：枠に相当する見た目。高さは時間長に従う
  - 演者ドラッグ時：演者コンポーネントに相当する見た目
- 時刻入力フィールド
  - 25時以降の表記（例: `25:05`）を受け付ける
  - タイムライン開始・終了時刻、演者要求の時刻項目で共用
- 確定付きテキストフィールド
  - アンフォーカスまたは Enter で確定。一字一字では確定しない
  - 入力に問題がある場合は確定しない
  - 数値（分・枠数）用のバリデーション付き変種を含む
- 枠タイプ選択
  - 既存から選択 or 新規作成
  - 新規の場合、枠タイプ名と時間長（必要なら出演枠属性）の入力
  - 既存の場合、枠タイプ名と時間長を編集不可で表示
  - 名前重複時は警告し、確定できないようにする
  - 出演枠属性の有無で候補を絞り込めること
- 要求項目エディタ
  - チェックボックス併設。チェックした場合にのみ入力が有効
  - 最低時間 / 最長時間 / 〜までに終了したい / 〜以降に開始したい / 〜番目以降を希望 / 〜番目より前を希望
  - 要求同士に矛盾がある場合、警告を表示し確定できないようにする
- 枠タイプリスト項目
  - 名前・時間長・出演枠属性を表示
  - ドラッグ元。クリックで選択
- 演者リスト項目
  - 名前・明示されている要求の内容を表示
  - ドラッグ元。クリックで選択
- 要求不一致警告表示
  - 警告色の小さいフォント。文言は固定
  - 演者コンポーネントおよび枠タイプ選択時の警告で共用
