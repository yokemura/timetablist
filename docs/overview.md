# 概要

タイムテーブル作成専用app

# 非機能仕様

- アプリ名: Timetablist
- プラットフォーム: Web
- 技術スタック
  - フレームワーク: Flutter / Dart
  - アーキテクチャ: RiverpodベースのMVVM (Freezed使用)
- アカウント不要
  - データ保存はローカルストレージ
  - データ引き継ぎはテキストによるエクスポート／インポート
- 英語 / 日本語対応
  - 言語切替はOS言語に従う
  - 仕様中、デフォルト名として示されている文言（「`転換`」等）も、ローカライズする
    - 一旦データとして確定したものは、後から翻訳はしない（日本語環境で「準備」というデフォルト命名がされたデータを、英語環境で開いた時に「Preparation」に修正したりはしない）
- 時刻・所要の表示形式
  - 特に個別の指定がなければ 24時間制・時間のゼロパディングなし(ex. 8:05)
- ArchemistによるVRT作成

# 基本フロー
- どんな枠タイプがあるか決める（演奏・転換）など
- タイムラインを作る
- 枠タイプを配置して実際の枠を作る
  - タイムラインがない場合は、配置しようとした時に作成を促す
- 枠に演者を割り当てる
  - 出演枠属性（[データ構造](data.md) 参照）を付与した枠には演者を割り当てられる

# 自動保存・アンドゥ
- ローカル保存は、データに変更があった時点で自動で行う
- データ変更は、ドラッグ操作・入力操作等が完結したタイミングでのみ行う
  - 特にテキストは、一字一字の入力は保存せず、アンフォーカス・Enter動作時に確定とする
    - ただし、入力に問題がある場合は確定しない
- アンドゥはデータ変更時を対象とする
- アンドゥはメモリにのみ保存する

# カラースキーム

- カラーは Material Design に基づいて決める
- 具体的な色指定は仕様としては定義しない（実装時に調整）
