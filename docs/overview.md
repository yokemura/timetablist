# 概要

タイムテーブル作成専用app

# 非機能仕様

- アプリ名: Timetablist
- iOS / Android / Web対応
- 技術スタック
  - フレームワーク: Flutter / Dart
  - アーキテクチャ: RiverpodベースのMVVM (Freezed使用)
- アカウント不要
  - データ保存はローカルストレージ＋テキストexport
- 英語 / 日本語対応
  - 言語切替はOS言語に従う
- 時刻・所要の表示形式
  - 特に個別の指定がなければ 24時間制・ゼロパディングなし
- ArchemistによるVRT作成

# 基本フロー
- どんな枠タイプがあるか決める（演奏・転換）など
- タイムラインを作る
- 枠タイプを配置して実際の枠を作る
  - タイムラインがない場合は、配置しようとした時に作成を促す
- 枠に演者を割り当てる
  - 出演枠属性（[データ構造](data.md) 参照）を付与した枠には演者を割り当てられる
